# Contributing to appjail

Thank you for helping. Everything you need is in the documentation:

- [Contributing](https://alberto743.github.io/appjail/develop/contributing/): the rules every change follows (standard
  library only, tests and documentation in the same commit, licensing, no personal data, git workflow).
- [Reading the source](https://alberto743.github.io/appjail/develop/source-tour/) and
  [Architecture](https://alberto743.github.io/appjail/develop/architecture/): how the code is organised.
- [Testing in the guests](https://alberto743.github.io/appjail/develop/testing/): nothing that runs software runs on
  your own machine, tests included.
- [Principles](https://alberto743.github.io/appjail/understand/principles/): a change that breaks one is a change of
  design; open an issue to discuss it first.

Bugs, blocked permissions, refused Wayland interfaces, apps that do not run, feature requests and documentation problems
each have an issue form. Vulnerabilities are reported privately: see [SECURITY.md](SECURITY.md).
